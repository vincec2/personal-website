Cloud Productivity Dashboard

Cloud Productivity Dashboard (CPD) is a Windows desktop app built with React and Electron. It stores projects, tasks, and productivity data locally in a JSON file under the user’s AppData/Roaming folder, with optional Firebase account sync. Features include customizable dashboard settings, a countdown/Pomodoro timer, and a 100-day focus challenge. Check link in the README.me in the repository to check out the app!

BODB

BODB is a full-stack business operations dashboard for small e-commerce businesses, built to help track products, suppliers, orders, expenses, customer issues, margins, and operational alerts in one place. It supports manual entry, CSV imports, searchable records, dashboard charts, and AI-generated business summaries, with a planned WooCommerce connector for syncing real store data.

PokeBinder

PokeBinder is a cloud-backed Pokémon card binder app built with React, TypeScript, AWS Lambda, DynamoDB, Cognito, and API Gateway. Users can create an account, make digital binders, search real Pokémon cards through the Pokémon TCG API, organize cards into visual binder pages, save layouts across devices, and generate public read-only share links.
